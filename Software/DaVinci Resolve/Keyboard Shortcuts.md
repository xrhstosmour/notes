#davinci-resolve #video-editing #keyboard-shortcuts

Core editing shortcuts:

| Key | Action |
| --- | --- |
| `I` | Set in point |
| `O` | Set out point |
| `J` | Play backward (tap repeatedly to increase speed) |
| `K` | Pause |
| `L` | Play forward (tap repeatedly to increase speed) |
| `K` + `J`/`L` | Slow-motion scrub backward/forward |
